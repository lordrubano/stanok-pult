# Пульт станка PDF→Excel

Открытая страница наблюдения за ходом плана. Только пульт и копия реестра
состояний. Код станка, документы и рабочие материалы здесь не публикуются.

- `index.html` — сам пульт, открывается в браузере
- `registry.csv` — реестр состояний, из которого пульт собран

Источник истины — реестр. Страница пересобирается из него одной командой.
