# Ящик отправки

Сюда станок кладёт то, что должно уйти наружу: отчёты о запусках, сводки,
артефакты для чтения на расстоянии. Всё, что здесь лежит, уходит наружу само —
человек в цепочке не участвует.

Отправку делает `exchange/send.py`: код станка вызывает `отправить()` сразу
после того, как артефакт записан, либо рядом работает сторож
`python exchange/send.py --следить`, который сам замечает новое и отправляет.
Дальше коммит в приватный `stanok` запускает публикацию через GitHub Actions,
и через минуту-две файл читается снаружи.

## Как читать снаружи

Страницы сайта отдаются с десятиминутным кешем раздатчика, и по ним нельзя
судить о свежести: файл уже лежит в хранилище, а наружу ещё десять минут идёт
прежний. Заголовками сайта станок не управляет.

Поэтому надёжная дорога другая — **читать по номеру коммита**. Содержимое
коммита неизменно, поэтому кеш на таком адресе безвреден: ответ либо тот самый,
либо его нет вовсе.

```
# 1. Живой номер коммита. Спрашивает сам сервер, не кешируется ничем.
git ls-remote https://github.com/lordrubano/stanok-pult.git main

# 2. Опись со всеми хешами, по этому номеру.
curl https://raw.githubusercontent.com/lordrubano/stanok-pult/<коммит>/outbox/opis.json

# 3. Любой файл, по тому же номеру.
curl https://raw.githubusercontent.com/lordrubano/stanok-pult/<коммит>/outbox/<имя>
```

Файл `opis.json` содержит имя, размер и SHA-256 каждого файла ящика. Прочитанное
снаружи сличается с этими хешами — и читателю не нужно верить никому на слово,
включая станок.

Для глаз остаются и прежние адреса, с оговоркой о кеше:

* опись — <https://lordrubano.github.io/stanok-pult/outbox/>
* отдельный файл — `https://lordrubano.github.io/stanok-pult/outbox/<имя>`

## Что сюда класть нельзя

Настоящие документы, журналы запусков и корпус наружу не уходят никогда.
Ящик пропускает только `.md`, `.txt`, `.csv`, `.json`, `.html`, `.svg`, `.png` —
рабочие форматы документов в списке отсутствуют намеренно. Сверх того файл
сверяется по содержимому с `corpus/` и `runs/`: копия оттуда узнаётся и наружу
не идёт.

Любой задержанный файл останавливает публикацию целиком, а не пропускается
молча. В журнале запусков GitHub Actions это видно красным.

Рубежей два, и правила у них общие: `send.py` проверяет ящик до коммита, чтобы
негодный файл не попал даже в историю приватного хранилища, а Actions проверяет
его ещё раз перед отправкой наружу. Оба рубежа проверены приманками вживую:
копия из `corpus/`, копия журнала из `runs/` и книга Excel были подложены в ящик
и наружу не ушли — публикация встала, а открытое хранилище осталось нетронутым.

## Открытость

Ящик лежит в открытом хранилище `stanok-pult` и виден всему свету, как и сам
пульт. Это канал наблюдения, а не хранилище тайн.
