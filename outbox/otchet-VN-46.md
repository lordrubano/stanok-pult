# Отчёт: архив переделан по тому, что увидел живой оператор

Дата: 06.08.2026. Работа вне нумерации. Все четыре причины названы владельцем и
все четыре — наши, а не оператора.

**Обезличено.** Проба шла на учебном документе.

## Что стало видно оператору

**Было:** архив → папка `stanok-dlya-operatora` → внутри ещё папка `stanok` →
семь файлов вперемешку, из них пять служебных, и оба нужных — в формате,
который Windows по щелчку не открывает.

**Стало:** архив → одна папка → **четыре файла и одна папка «служебное»**:

```
1 ПРОЧТИТЕ ПЕРВЫМ.txt        3 363 байта
2 ЗАПУСТИТЬ СТАНОК.cmd       4 004 байта
3 ОСТАНОВИТЬ.cmd               506 байт
Инструкция оператора.txt    12 915 байт
служебное\                   (внутренности станка)
```

Имена начинаются с цифр не для красоты: **Windows ставит цифры перед буквами**,
и первым в списке оказывается ровно тот файл, который надо прочесть. Порядок
чтения виден без объяснений — 1, 2, 3.

Оба текста стали `.txt`: открываются по двойному щелчку блокнотом. Заголовки
подробной инструкции переведены в простой текст — разметки, которую человек не
обязан понимать, там больше нет.

Служебное убрано в папку. Оператор больше не видит `stanok.sostav.json` и не
гадает, трогать его или нет; в первом файле про эту папку сказано одной
строкой: «внутренности станка, трогать не нужно».

## Запуск из архива теперь говорит словами

Люди действительно не распаковывают: Windows показывает архив как папку, и это
выглядит убедительно. Запуск оттуда сработать не может — Windows кладёт файлы
во временное место, а изделия рядом нет.

Теперь запуск это **замечает сам** и вместо ошибки печатает:

> **Станок запущен из архива, а так он работать не может.**
> Windows показывает архив как обычную папку, но это не папка: файлы внутри неё
> ещё сжаты, и программа оттуда не работает.
> 1. Закройте это окно. 2. Найдите сам файл архива: `stanok-dlya-operatora.zip`.
> 3. Щёлкните по нему **правой** кнопкой. 4. Выберите «Извлечь все…» и нажмите
> «Извлечь». 5. Откроется настоящая папка — запускайте станок уже из неё.

Узнаётся это тремя признаками: временная папка вида `Temp1_…`, путь внутри
`AppData\Local\Temp`, и отсутствие рядом папки «служебное». Любого из трёх
довольно.

## Проверено как человеком, обоими путями

| Что проверял | Итог |
|---|---|
| распаковал архив | одна папка, вложений нет; четыре файла и «служебное» |
| первый файл в списке | «1 ПРОЧТИТЕ ПЕРВЫМ.txt», открывается блокнотом |
| **запустил прямо из архива** | предупреждение напечатано, станок не запустился |
| читается ли предупреждение по-русски | да — проверено в настоящем окне с кодовой страницей 65001 |

| папка работы | создалась сама |

## Дефекты

**Все четыре причины — наши.** Ни одна не про оператора: он сделал ровно то,
что делает большинство, и уткнулся в устройство, которое мы ему дали.

Отдельно стоит четвёртая — формат файлов. Я собрал архив для человека, который
не работал в командной строке, и положил ему тексты в формате, который его
Windows не открывает. Это не мелочь: человек не прочёл ни одной строки из
написанного для него.

## Мои ошибки

**Проверял архив прогоном, а не глазами.** Мои пробы распаковывали архив
кодом — то есть делали именно то, чего человек не делает. Путь «зашёл внутрь
архива как в папку» я не проверял ни разу, хотя он самый частый.

**Считал вложенность и служебные файлы мелочью.** Они и есть та стена, о
которой человек спотыкается молча: он не пишет «у вас вложенная папка», он
просто закрывает окно.

## Чего нельзя утверждать

* **Что теперь оператор справится.** Проверено, что препятствия, которые он
  назвал, убраны. Не споткнётся ли он о следующее — покажет вторая попытка;
* **Что предупреждение поймают все случаи запуска из архива.** Признаков три,
  и на другом архиваторе путь может выглядеть иначе;
* **Что «3 ОСТАНОВИТЬ» кладёт станок наверняка.** Не кладёт, и в текстах первым
  назван верный способ — закрыть чёрное окно;
* **Что тексты понятны.** Они написаны тем, кто станок собирал.

## Проверки

Проверок в станке **1 942**, все зелёные. Архив проверен пробой «как у
человека» обоими путями — и распакованным, и прямо из архива.
