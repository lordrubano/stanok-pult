# Отчёт: архив оператора — распаковал, щёлкнул, работает

Дата: 06.08.2026. Работа вне нумерации по решению владельца: оператору один
архив, без командной строки.

**Обезличено.** Проба шла на учебном документе.

## Что в архиве

`stanok-dlya-operatora.zip`, **645 КБ**, семь файлов:

| Файл | Для чего |
|---|---|
| `ЗАПУСТИТЬ.cmd` | щелчок мышью: проверяет язык, спрашивает имя, поднимает станок, **сам открывает браузер** |
| `ОСТАНОВИТЬ.cmd` | вспомогательная остановка |
| `С-ЧЕГО-НАЧАТЬ.md` | одна страница: распаковал → щёлкнул → открылось → дальше вот это |
| `ИНСТРУКЦИЯ-ОПЕРАТОРА.md` | подробно: каждый экран, каждый цвет, чего ждать на выходе |
| `stanok.pyz` | изделие; учебный документ **внутри** |
| `stanok.sostav.json`, `stanok.опись.json` | состав выпуска и отпечаток |

**Имя оператора** спрашивается при первом запуске и запоминается в
`имя-оператора.txt` рядом. Так проще для человека: один раз набрал — дальше не
спрашивают, а поправить можно блокнотом.

**Рабочий каталог создаётся сам** рядом с файлом запуска, и путь к нему
безусловный — не зависит от того, откуда щёлкнули.

## Если Python нет — человеческими словами

В окне появляется не «требуется Python 3.11+», а шесть шагов: открыть
python.org, нажать большую жёлтую кнопку, запустить скачанное, **поставить
галочку «Add python.exe to PATH» — она внизу окна, без неё станок Python не
найдёт**, нажать Install Now, закрыть окно и щёлкнуть ЗАПУСТИТЬ снова. И
отдельно: если галочку забыли — поставить заново поверх, с галочкой.

## Служебная группа больше не первая

Исправлено то, что я сам назвал дефектом: крупнейшая связка на любом документе
— «слагаемое допуска не выполнено», её даёт движок каждой записи, ушедшей
человеку. Стоя первой, она уводила оператора разбирать не то.

Теперь читаемые группы идут впереди служебной. Проверено: очередь говорит
«Разобрать группу „двоякая дата" — 213 записей», и экран группы показывает её
же. Сами связки не изменились — изменился только порядок показа.

## Дефекты

**Найден пробой и закрыт: папка работы не появлялась.** Путь к ней был
относительным и зависел от того, из какого места щёлкнули. Сделан безусловным —
от файла запуска.

**Найден пробой и назван честно: `ОСТАНОВИТЬ.cmd` не всегда кладёт станок.**
Способ через имя окна и разбор списка портов на моей машине сработал не всегда,
и выдавать его за надёжный я не стал. Поэтому в инструкции **первым назван
верный способ — закрыть чёрное окно**: пока окно живо, станок работает; окна нет
— станка нет. Файл остановки остался как вспомогательный, и в нём написано, что
делать, если не помогло.

**Найдена своя ошибка в самой пробе.** Первая проба говорила с чужим станком:
на порту висел процесс от зависшего прогона получасом раньше, и я едва не
записал в дефекты исправную работу. Порт освободил и проверил набело.

## Чего нельзя утверждать

* **Что архив запустится на машине оператора.** Проверен на чистом месте нашей;
  чужой машины у станка по-прежнему не было;
* **Что остановка сработает файлом.** Верный способ — закрыть окно, и он назван
  первым;
* **Что человек не растеряется.** Командной строки больше нет, но чёрное окно
  осталось, и для многих оно само по себе — препятствие;
* **Что порядок групп теперь правильный.** Он стал полезнее: читаемое впереди
  служебного. Правильный порядок по важности — отдельная работа.
