## Канал обмена

Обмен с внешним миром идёт через GitHub, а не через приложение Google Диска.
Станок кладёт файл в `exchange/outbox`, `exchange/send.py` тут же отправляет
ящик, GitHub Actions публикует, и через минуту-две файл читается снаружи по
постоянной ссылке. Действий человека в цепочке нет ни одного.

Что наружу не уходит никогда: настоящие документы, журналы запусков, корпус.
Проверено приманками и на бумаге (`tests/test_outbox_guard.py`, `tests/test_send.py`),
и вживую: подложенные копии из `corpus/` и `runs/` вместе с книгой Excel
остановили публикацию, наружу не ушло ничего.
